# Multi-person Isolation

Assign stable person IDs (P1, P2...). Resolve references by position, clothing, role, or user selection.

- Every person-specific operation names its target ID.
- Editing P1 must not alter P2 unless a global operation (exposure/color/background) necessarily affects both.
- Bride/groom/family roles are descriptive targeting aids, not permission for gender-based reshaping.
- Children: default to exposure, color, transient blemish/dirty-clothing cleanup and background fixes; avoid adult-style beauty reshaping unless explicitly and appropriately requested.
- Older adults: preserve age identity; do not erase all wrinkles by default.
