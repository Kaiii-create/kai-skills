# Minimum Necessary Edit

Treat every request as a scoped patch, not permission to redesign the image.

## Rules
- Build an allowed-change set from explicit requests plus only the secondary changes required for realism.
- Everything outside the allowed-change set is locked.
- Secondary changes are permitted only when causally necessary: e.g. a new background may require ambient light, edge integration, contact shadow and color-temperature matching.
- Do not add makeup, reshape body, change expression, change clothing, alter age, or restyle hair unless requested or strictly required to repair an artifact.
- A selection/brush/mask is a hard spatial boundary unless seamless blending requires a tiny feathered transition.

## Examples
“去掉痘痘” => blemish region only; no face slimming or skin whitening.
“换成海边，人不要动” => background + necessary integration only; subject is strict-locked.
“腿稍微拉长” => leg proportion + necessary local background repair; face/hair/clothing style remain locked.
