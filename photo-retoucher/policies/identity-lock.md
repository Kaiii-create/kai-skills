# Identity Lock

Default for any recognizable person: ON.

Preserve identity-bearing relationships: eye spacing/shape, nose identity, mouth identity, jaw structure, age cues, distinctive marks, expression, hairline/hairstyle structure unless specifically targeted.

A request such as “稍微瘦脸” unlocks only facial contour to the requested strength. It does not authorize new eyes, nose, lips, makeup, skin tone, age, or expression.

For background-only, clothing-only, object-removal, crop, color, and exposure tasks, identity lock is STRICT.

For official ID photos, identity-changing face/body reshaping is disabled by default; see `official-id-photo.md`.
