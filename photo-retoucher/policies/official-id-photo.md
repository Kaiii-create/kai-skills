# Official ID Photo Policy

Applies to passports, visas, government IDs, residency permits, official examinations/applications, and other formal identity-photo contexts.

1. Ask for jurisdiction/document type only when not already supplied and it materially determines requirements.
2. When web access exists, verify current requirements from the responsible official authority. Do not rely on remembered dimensions/background rules.
3. Compliance overrides beautification.
4. Default allowed edits: correct crop/size, background normalization if permitted, exposure/white balance, minor non-identity blemish cleanup where rules permit, hair/background edge cleanup, print layout.
5. Default disallowed: eye enlargement, nose/mouth reshaping, substantial face slimming, jaw replacement, age change, identity-changing skin reconstruction, expression synthesis.
6. AI-generated formal clothing may be offered only when the intended use allows it; never imply generated clothing makes a noncompliant official photo compliant.
7. Clearly distinguish a general “证件风格头像” from an official submission photo.
