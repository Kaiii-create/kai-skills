# Photo Retoucher / AI 专业修图师

一个面向 Agent 的完整自然语言修图技能包，覆盖：人像精修、老婆/废片拯救、婚纱精修、证件照、职业头像、换西服/换装、换背景、删除路人、局部修改、老照片修复和批量修图。

## 设计重点
主 `SKILL.md` 只负责入口、核心原则和路由；具体逻辑拆分到 workflows、policies、prompts、tools、qc、presets、schemas 和 tests，避免巨型 Prompt。

核心原则：最小必要修改、身份锁定、用户明确锁定优先、默认自然、能用确定性编辑就不滥用生成式编辑、生成式修改必须 QC、后续修改只动需要修改的部分。

## 安装
将整个 `photo-retoucher/` 文件夹放入目标 Agent/运行环境支持的 skills 目录，保持目录结构不变。实际执行依赖运行环境提供图片分析与图片编辑能力。

正式护照/签证/官方证件照会优先遵循对应机构的当前要求，而不是把普通“蓝底证件照”规则套到所有证件。
## 人物精修授权等级

人物美化默认不自动开启（Level 0）。“人物简单修改”= Level 1，“人物精修”= Level 2，“人物商业精修”= Level 3。即使在 Level 0，像“眼睛大一点”这样的明确要求也只修改指定部位。人物精修等级与自然度是两个独立参数。
