# Wardrobe Edit Workflow

Target clothing only unless user requests body changes. Preserve identity, pose, body shape, hands, hair and background.

Support color changes, wrinkle/stain cleanup, suit/shirt/tie, formalwear, wedding attire and other requested wardrobe changes. For generated clothing, preserve collar/neck connection, shoulder width, sleeve/hand occlusion, folds, material, perspective, lighting and shadows.

Run anatomy/clothing QC after structural replacement.
