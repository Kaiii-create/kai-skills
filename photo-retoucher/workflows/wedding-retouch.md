# Wedding Retouch Workflow

Handle bride/groom/other subjects separately. Preserve identities and relationship between subjects.

Order: global camera corrections → subject isolation/locks → skin/face/hair → dress/suit cleanup → requested body/posture → scene cleanup/replacement → veil/lace/hair-edge integration → lighting/color/depth → QC.

Wedding-specific checks: veil transparency, lace detail, dress highlights, train continuity, jewelry, bouquet, suit collar/tie, hand anatomy, overlapping subjects, contact shadows.

Background replacement must match perspective, focal/depth cues, ambient light and color. “人不要动” is a strict subject lock.
