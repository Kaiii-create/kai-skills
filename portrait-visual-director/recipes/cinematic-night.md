# cinematic-night

# Intent

Night film-still portraiture — motivated practicals, readable subject, controlled color, real shadow.

# Visual Direction

One coherent night key story. Background layers support the subject; darkness has structure.

# Preferred State Patches

| Path | Direction | Strength |
|------|-----------|----------|
| `environment.time_context` | Night | NORMAL |
| `lighting.source` | Practicals / street / window spill / motivated sign light | NORMAL |
| `lighting.quality` | Mixed soft-hard; specular where wet/metal | NORMAL |
| `lighting.direction` | Key + separation; avoid flat frontal fill | NORMAL |
| `color.palette` | Controlled night chroma (not auto-neon) | NORMAL |
| `color.grade` | Filmic, protected blacks | NORMAL |
| `moment` | Still-frame beat (wait, turn, step) | SUBTLE |
| `composition` | Depth / layering for night space | NORMAL |
| `texture.surface` | Wet asphalt, glass, fabric sheen when motivated | SUBTLE |
| `camera.depth` | Face sharp, bg falloff | SUBTLE |

# Director Guidance

Subject readability first. One primary motivated key story; background practicals secondary. Do not stack daylight + neon + studio rim without repair.

# Compatible References

Lighting INSPIRE may seed mood; identity LOCK stays. Environment IGNORE on a ref still allows recipe night env if user asked night.

# Protective Check

The face remains readable, the subject has separation from the environment, and all visible highlights/shadows can be explained by one primary motivated key story plus secondary practicals. Neon quantity alone is not evidence of cinematic direction.

# Must Not Override

User HARD noon daylight, LOCK lighting if user locked, FORBID text overlays, identity.

# Avoid

Assuming neon = cinematic; four equal light sources; crushed unreadable faces; cyber clutter by default.
